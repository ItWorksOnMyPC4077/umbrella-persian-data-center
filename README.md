## 📝 توضیحات پروژه (Project Description)

### 🇮🇷 [فارسی]
این پروژه شامل یک صفحه فرود (Landing Page) حرفه‌ای برای معرفی خدمات یک مرکز داده (Data Center) است. طراحی این صفحه با تمرکز بر تجربه کاربری (UX) و رابط کاربری (UI) مدرن انجام شده و شامل بخش‌هایی نظیر خدمات، ویژگی‌های امنیتی و تماس با ما می‌باشد. این پروژه برای نمایش مهارت‌های طراحی وب و ساخت ساختارهای HTML/CSS توسعه یافته است.

### 🇬🇧 [English]
This project is a professional landing page designed to showcase Data Center services. The design focuses on modern User Experience (UX) and User Interface (UI) principles, featuring sections such as Services, Security Features, and Contact Information. This project demonstrates web design skills and the implementation of clean HTML/CSS structures.

## 🛠 تکنولوژی‌های استفاده شده (Tech Stack)

| Technology | Role | نقش در پروژه |
| :--- | :--- | :--- |
| **HTML5** | Structure | ساختار اصلی صفحه |
| **CSS3** | Styling | استایل‌دهی و چیدمان (Layout) |

## ✨ ویژگی‌های کلیدی (Key Features)

* **🌐 Responsive Design:** کاملاً واکنش‌گرا و مناسب برای تمامی نمایشگرها (موبایل، تبلت، دسکتاپ).
* **🛡️ Modern UI:** استفاده از المان‌های مدرن برای ایجاد حس اعتماد و امنیت (مناسب برای حوزه دیتاسنتر).
* **🎨 Clean Code:** کدنویسی تمیز و سازمان‌یافته مطابق با استانداردهای وب.
* **🌓 RTL/LTR Support:** پشتیبانی از چیدمان راست‌چین (برای فارسی) و چپ‌چین (برای انگلیسی).
